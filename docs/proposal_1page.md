## 1. 가상 직군
한국공항공사 김해공항 운영기획부 데이터분석 담당자

## 2. 골든서클
- **Why**: 김해공항은 아침 시간대에 출발편과 탑승객이 몰리고, 이 시간대에 지연도 잦다. 승객은 공항에 언제 도착해야 할지 모르고, 공사는 혼잡 시간대 인력 배치 근거가 부족하다.
- **How**: 공공 API 4개를 GitHub Actions로 하루 2회 자동 수집하고, 날씨와 결합해 시간대·요일·항공사·국내/국제·날씨별 지연율과 탑승객 수를 분석한다.
- **What**: ① 승객용 **공항 도착시간 계산기** (시간대별 탑승객 수 기반 권장 도착 시각) ② 공사용 **혼잡·지연 대시보드** (시간대×요일 히트맵, 인력 배치 제안)

## 4. 예비 관찰 (6일치, 2026-11-9~14 · 최종 분석 전 참고용)
- 실제 운항편 1,878편 중 사전결항 34편(1.8%).
- 지연 기준: 국토부 현행 기준인 **예정보다 15분 초과**(게이트 기준). 단, API의 실제 시각이 게이트 출발인지 이륙인지 명세에 없어 **측정 시점 확인 중**.
- 출발편 920편 중 **15분 넘게 늦은 편 38.4%** (국내선 출발 43.1%, 국제선 출발 36.1%). 도착편은 국내 13.3%, 국제 12.7%.
- 참고로 2024년 전국 국내선 지연율은 22.2%(국토부 집계, 한경비즈니스 2025-02 보도)다. 김해 국내선은 출발 43.1%, 출·도착 합산 28.2%로 이보다 높게 나타났다. 다만 측정 시점과 집계 방식이 같은지는 확인이 필요하다.
- 출발 지연 비율은 **07~08시 49~54%**, 21~22시 51~59%로 높고, 09~11시는 22~27%로 낮다.
- 1년치 출발 탑승객(API 제공값)은 **07·08시가 시간당 평균 약 2,600명**으로 가장 많고, 15시(약 970명)의 약 2.7배다.
→ "탑승객이 많은 아침 시간대에 지연도 많다"는 가설을 4주치 데이터로 검증한다.

## 7. 경영 분석 요약 (수치는 최종 분석 결과로 채움)
- **3C**: Company 운항·탑승객 데이터를 직접 가진 공사 / Customer 언제 출발해야 할지 모르는 출장·여행·가족·첫 이용객 / Competitor 항공사 앱·포털 항공편 조회는 "내 편 상태"만 알려줄 뿐 공항 혼잡 기반 도착 시각은 없음
- **7P**: Product 도착시간 계산기+대시보드 / Price 무료(공사 가치는 민원·인력비 절감) / Place 웹·공항 키오스크·예약 문자 링크 / Promotion 공항 안내 QR / People 운영기획·현장 보안검색 인력 / Process 수집→분석→계산기·대시보드→인력 배치 / Physical Evidence "최근 ○주 ○○편 기준" 출처 표시
- **SWOT**: S 공사 보유 데이터·자동 수집 / W 수집 기간이 짧아 성수기 패턴 없음, 보안검색 대기시간 데이터 없음 / O 국제선 수요 증가, 가덕도신공항 개항 전 운영 효율화 필요 (출처 확인 필요) / T 항공사 앱 등 대안, 예측이 빗나가면 신뢰 하락
- **BMC**: 고객 = 김해공항 출발 승객·공사 운영부서 / 가치 = "몇 시에 도착하면 되는지"와 "언제 인력이 필요한지" / 핵심 자원 = 공공 API 데이터·수집 파이프라인 / 수익 = 직접 수익 없음, 민원·인력 운영비 절감
