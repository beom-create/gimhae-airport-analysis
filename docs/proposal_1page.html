2. 골든서클

Why김해공항은 아침 시간대에 출발편과 탑승객이 몰리고, 이 시간대에 지연도 잦다. 승객은 공항에 언제 도착해야 할지 모르고, 공사는 혼잡 시간대 인력 배치 근거가 부족하다.
How공공 API 4개를 GitHub Actions로 하루 2회 자동 수집하고, 날씨와 결합해 시간대·요일·항공사·국내/국제·날씨별 지연율과 탑승객 수를 분석한다.
What① 승객용 공항 도착시간 계산기 (시간대별 탑승객 수 기반 권장 도착 시각) ② 공사용 혼잡·지연 대시보드 (시간대×요일 히트맵, 인력 배치 제안)

4. 예비 관찰 (6일치, 2026-11-09~14 · 최종 분석 전 참고용)

  • 지연 기준: 국토부 현행 기준인 예정보다 15분 초과(게이트 기준). 단, API의 실제 시각이 게이트 출발인지 이륙인지 명세에 없어 측정 시점 확인 중.
  • 실제 운항편 1,878편 중 사전결항 34편(1.8%).
  • 출발편 920편 중 15분 넘게 늦은 편 38.4% (국내선 출발 43.1%, 국제선 출발 36.1%). 도착편은 국내 13.3%, 국제 12.7%.
  • 2024년 전국 국내선 지연율 22.2%(국토부 집계)와 비교하면, 김해 국내선은 출발 43.1%, 출·도착 합산 28.2%로 높게 나타났다. 단, 측정 시점과 집계 방식이 같은지는 확인이 필요하다.
  • 출발 지연 비율은 07~08시 49~54%, 21~22시 51~59%로 높고, 09~11시는 22~27%로 낮다.
  • 1년치 출발 탑승객(API 제공값)은 07·08시가 시간당 평균 약 2,600명으로 가장 많고, 15시(약 970명)의 약 2.7배다.
→ 가설: "탑승객이 많은 아침 시간대에 지연도 많다"를 4주치 데이터로 검증한다. (21~22시 지연은 탑승객 수만으로 설명되지 않아 별도 확인)
