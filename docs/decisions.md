## 탑승객 수: 사전 산출된 "예상치"로 판단 (2026-11-17 검증)

- 근거 1: 매일 **01시대 수집에서 그날 06~22시 전체 값이 이미 들어와 있음** (11/14 01:14, 11/15 01:00, 11/16 01:03, 11/17 01:52 첫 수집에 각 62~64행). 아직 운항 전인 시간대의 실측값은 있을 수 없음.
- 근거 2: 운항일이 지난 뒤 다시 받은 752행(11/5~)에서 **값이 바뀐 경우 0건**. 바뀐 기록은 1건뿐이고 그것도 운항 전날 → 당일 사이(11/13 13시 국내 도착 117 → 237).
- 결론: 이 API 값은 **운항 전에 만들어지는 예상 탑승객 수**이며, 사후에 실적으로 갱신되지 않는다. 1년치 백필 값도 같은 성격으로 본다.
- 표기: 보고서·웹에서 **"예상 탑승객 수(한국공항공사 제공)"**로 쓴다. "실측", "실제 탑승객"은 쓰지 않는다.
- 분석 의미: "탑승객이 많은 시간대에 지연도 많나?"는 "**혼잡이 예상된 시간대**에 지연도 많나?"로 해석한다. 계산기에도 "공사 예상 기준"으로 표시. 실적 기반 수치는 공공데이터포털의 월별 실적 파일(CSV) 사용 가능 여부를 별도 확인.

### 측정 시점: 데이터로 검증한 결과 "이륙·착륙(활주로) 기준"으로 추정 (2026-11-17)

- 방법: 김해↔제주·김포 국내선 301편(11/14~16)을 상대 공항 기록과 짝지어, (도착 실제시각 − 출발 실제시각)을 예정 소요시간과 비교. 예정시각은 항공권 기준이라 게이트~게이트(블록) 시간.
- 결과 (중앙값):

| 노선 | 편수 | 예정 소요 | 실제 소요 | 차이 |
|---|---|---|---|---|
| 김해→제주 | 86 | 60분 | 43분 | −19분 |
| 제주→김해 | 86 | 60분 | 36분 | −25분 |
| 김해→김포 | 64 | 65분 | 43분 | −23분 |
| 김포→김해 | 65 | 65분 | 41분 | −24분 |

- 해석: 실제 시각이 게이트 기준이면 실제 소요가 예정(블록)과 비슷해야 하는데, 평균 23분 짧다. 이는 지상 활주 시간(출발 택시아웃 + 도착 택시인)이 빠진 **비행시간**에 해당 → 출발 = 이륙, 도착 = 착륙 시각일 가능성이 높다. 제주→김해가 반대 방향보다 7분 짧은 것도 편서풍(뒷바람) 효과로 비행시간 해석과 맞는다.
- 한계: 명세로 확인한 것이 아니라 데이터로 추정한 것. 공사 문의(02-2660-4803)로 최종 확인 필요. 원자료: `data/sample/timing_check/` (제주·김포의 김해행 출발, 김해발 도착 기록 11/14~16).
- **영향**: 우리 "지연" = 이륙 시각 − 예정 게이트 출발 시각 = 게이트 지연 + 택시아웃(약 10~15분 추정). 그래서 현행 국토부 기준(게이트 15분 초과)을 그대로 적용하면 **출발 지연율이 과대 추정**되고, 도착은 택시인이 빠져 **과소 추정**된다.

| 11/9~16 (실제 운항편) | 15분 초과 | 구 기준 (국내 30분·국제 60분 초과, 활주로 기준) |
|---|---|---|
| 출발 국내 (397편) | 40.3% | 8.6% |
| 출발 국제 (833편) | 36.6% | 4.2% |
| 도착 국내 (398편) | 13.1% | 6.3% |
| 도착 국제 (838편) | 13.0% | 1.9% |

- 결정 필요: 측정 시점이 활주로 기준이면, **같은 활주로 기준인 구 기준(30/60분)**이 데이터와 정의가 맞는다. 15분 기준을 유지하려면 "이륙 기준 15분 초과(택시아웃 포함)"라고 명시해야 국토부 게이트 기준 지연율(2024 국내선 22.2%)과 직접 비교하지 않게 된다. → **2026-11-19 결정: 타겟은 구 기준(국내 30분·국제 60분 초과)**. 15분 초과는 참고용 컬럼(`delayed_gate15_ref`)으로만 계산.

### (이전 기록) 측정 시점: 확인 중
- 운항정보 GW 명세의 `estimateddatetime` 설명은 "실제 또는 변경시간"뿐이고, **게이트 출발(블록아웃)인지 이륙인지 정의가 없음**. `/detail`의 `ETD`도 "실제 출발시간"으로만 적혀 있음.

- 타겟 = 출발 지연(구 기준). feature = 운항 전에 알 수 있는 값만. 모델 = 로지스틱 회귀(가중치) + 랜덤포레스트(중요도).
- 불균형: 11/9~18 출발 1,537편 중 지연 85편(5.5%; 국내 9.1%, 국제 3.8%) → `class_weight=balanced` + 판정 기준값을 학습 데이터 교차검증으로 F1 최대가 되게 조정.
- 분할: 날짜 순서(앞 75% 학습 / 뒤 25% 테스트). 무작위 분할은 같은 날 같은 날씨·혼잡이 양쪽에 들어가 성능이 부풀 수 있음.
- 강수 플래그 9 처리: 부산(159)으로 보완 후 남는 결측은 "기록결측" 범주 (docs/preprocessing_rules.md).
- 지금(10일치) 숫자는 예비. 요일 feature는 요일당 1~2일뿐이라 날짜 효과와 섞여 있음 → 12월 4주치로 재실행 후 해석.

## 운항정보 메모

- **(2026-11-15 정정)** 실제 운항편 = `masterflightid`가 비어 있거나 자기 편명과 같은 행. 그 외(마스터가 다른 편명)는 같은 비행기를 다른 항공사가 판매하는 중복이라 분석에서 제외.
  - 처음엔 `codeshare = Y`를 전부 뺐는데, Y에는 운항사 본편도 들어 있었음 (예: 11/13 06:45 제주행 BX8685는 Y이면서 마스터 = 자기 자신, LJ3743·OZ8105가 판매 편명). 그 규칙으로는 국내선 출발이 하루 22편으로 과소 집계됐고, 정정 후 49편.
  - 11/9~11/14 기준 3,466행 중 실제 운항편 1,878편.
- 한국공항공사 GW는 `numOfRows=1000`이면 게이트웨이 오류(04) → 100으로 페이지 순회.
