# 김해공항 출발 지연 예측 — 분석 보고서 (자동 생성 초안)

> ⚠️ **예비 결과**: 2026-11-09 ~ 2026-11-18 (10일) 데이터, 생성 2026-11-19T22:17:07+09:00. 12월에 4주치로 다시 실행해 숫자를 확정한다.
> 테스트 지연 표본이 적어 지표가 크게 흔들릴 수 있음.

## 1. 가상 직군
한국공항공사 김해공항 운영기획부 데이터분석 담당자

## 2. 모델링 목적
운항 **전에** 알 수 있는 정보(예정 시각·요일·항공사·목적지·혼잡 예상·직전 날씨)만으로 출발편의 **지연 여부**를 예측하고,
어떤 요인이 지연 가능성을 높이는지 가중치로 설명해 혼잡 시간대 인력 배치와 승객 안내에 활용한다.

- 타겟: 출발 지연 = 실제 출발 − 예정 출발 > 국내 30분 / 국제 60분 (국토부 구 기준)
  - API 실제 시각이 이륙(활주로) 기준으로 추정되어, 같은 활주로 기준인 구 기준을 사용 (docs/decisions.md)
- 전체 지연율 5.5% → 클래스 불균형 처리: ① `class_weight=balanced`(지연편에 더 큰 가중치) ② 판정 기준값(threshold)을 학습 데이터 교차검증으로 F1 최대가 되게 조정. 평가는 지연 클래스의 Precision / Recall / F1
- 표의 `threshold`=적용한 기준값, `f1_at_0.5`=기준값 0.5 고정 시 F1(비교용), `cv_f1_train`=학습 데이터 교차검증 F1(안정성 확인용)
- 분할: 날짜 순서 — 학습 1232편 (2026-11-09 ~ 2026-11-16), 지연 69편 / 테스트 305편 (2026-11-17 ~ 2026-11-18), 지연 16편

### 3-3. Feature 조정·가중치
조정 내용 (학습 데이터로만 결정):

- 예정 출발 시각(sched_hour) → 시간대 구간(time_band) 범주로 변환
- 요일 숫자(dow) → 요일 범주(dow_name)로 변환
- 직전 3시간 강수량·결측 지표 → 강수 상태 3분류(비/없음/기록결측)로 통합
- is_holiday: 학습 데이터에서 값이 하나뿐(상수) → 제외
- sched_dep_same_hour ↔ exp_pax_total_hour 상관 0.94 > 0.8 → 중요도 낮은 sched_dep_same_hour 제외
- is_weekend: 조정 전 RF 중요도 0.7% < 2% → 제외
- airline: 학습 데이터 30편 미만 14개 범주 → '기타'로 묶음
- dest: 학습 데이터 30편 미만 35개 범주 → '기타'로 묶음
